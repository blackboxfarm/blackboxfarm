Internal Development Record

BlackBox Farm

Full-stack development timeline covering November 2025 through April 2026 — from initial token registry to AI-powered intelligence platform. ~10,000 messages condensed.

01

November 2025 Foundation & Data Ingestion

Key Decisions
  • Adopted a single scraped_tokens table as the canonical token registry, consolidating data from multiple scraping sources
  • Established a "tight display" design philosophy — minimal padding, maximum data density across all admin interfaces
  • Chose Supabase as the unified backend for auth, database, edge functions, and storage
Architecture
  • React 18 + Vite + Tailwind CSS + TypeScript frontend
  • Supabase backend with PostgreSQL, Edge Functions (Deno), and Row-Level Security
  • Helius API for Solana RPC and token metadata
02

December 2025 Trading Infrastructure & Advertising Platform

Banner Advertising System

  • Created the self-service advertiser portal (/buy-banner) with tiered pricing (1hr test tier through 30-day packages)
  • Built payment flow with Solana wallet generation per advertiser, payment detection, and automatic banner activation
  • Developed admin Advertiser Management panel for monitoring accounts, orders, wallet balances, and banner images
  • Implemented auth modal integration to preserve form state during sign-up/login flow

Telegram Channel Monitor & Fantasy Portfolio

  • Built real-time Telegram channel monitoring via bot webhook — ingests token calls from monitored alpha groups
  • Created the Fantasy Portfolio Dashboard — automatically opens fantasy positions on first token mention, tracks price performance, and attributes calls to specific channels
  • Implemented deduplication logic: one token = one fantasy position, earliest mention wins across all channels
  • Added channel-specific caller attribution with proper group name display

Developer Intelligence System (Genesis)

  • Extended developer_profiles, developer_wallets, and developer_tokens tables for tracking token creators
  • Implemented wallet genealogy tracing — follows the funding chain from token mint wallet back through intermediary wallets to the KYC root (Binance, Coinbase, etc.)
  • Added developer risk classification with badges: rug history, wallet bundling detection, slow bleed patterns
  • Integrated developer risk scoring into the Fantasy Portfolio's buy/sell decisions

Security Hardening

  • Fixed advertiser wallet secret exposure — restricted RLS so users can only access their own accounts
  • Removed redundant creator wallet columns after identifying data display duplication
  • Implemented proper auth flow to prevent data loss during banner purchase sign-up
Key Decisions
  • Chose Jupiter as the primary swap aggregator with PumpPortal fallback for bonding curve tokens
  • Adopted encrypted private key storage pattern — keys never exposed to the frontend
  • Decided to run developer genealogy traces before buy execution to inform trading decisions
  • Established the "never disable the buy button" principle — warnings are informational, never blocking

January 2026 Analytics, Sharing & Token Analysis

Wallet Genealogy Scanner

  • Created the wallet-genealogy-scanner edge function for deep funding chain analysis
  • Identifies known CEX hot wallets (Binance, Coinbase, Kraken, etc.) as funding origins
  • Traces multi-hop funding paths and records the full genealogy tree

FlipIt Enhancements

  • Fixed P&L percentage calculations to use value-based math instead of price-based
  • Implemented position verification with on-chain balance reconciliation
  • Added Scalp Mode for rapid entry/exit trading patterns
  • Integrated RugCheck.xyz data for pre-trade risk assessment

Pump.fun Monitor Pipeline

  • Built the real-time Pump.fun token discovery pipeline with WebSocket integration
  • Implemented multi-gate qualification system: duplicate ticker check, developer risk check, bonding curve progress, holder distribution analysis
  • Created the Pipeline Debugger for visualizing token flow through qualification gates
  • Added KOL (Key Opinion Leader) tracking for monitoring influencer token mentions
Key Decisions
  • Chose Satori over AI-based image generation for share cards — deterministic, fast, and consistent output
  • Implemented Cloudflare Workers for domain-level proxy rather than subdomain redirects
  • Adopted a multi-gate pipeline architecture for token qualification — each gate independently pass/fail with configurable thresholds
04

February 2025 Intelligence Network & Automation

Blacklist Mesh Guard

  • Implemented instant blacklist checking on manual token entry in FlipIt — runs in parallel with price fetching
  • Deep funding-chain analysis cross-references the reputation mesh for known bad actors
  • Warning-only approach: displays risk information without blocking trade execution

Master Wallets Dashboard

  • Built comprehensive wallet management with inline label editing, balance tracking, and token account management
  • Implemented Reclaim Rent utility — closes empty token accounts to recover SOL, verified to not create wallet bundling breadcrumbs
  • Added wallet pool organization with sortable cards and nickname support

Banker Pool (Automated Trading)

  • Created the rule-based automated trading system with configurable entry/exit criteria
  • Implemented position sizing, stop-loss, take-profit, and trailing stop mechanisms
  • Built daily P&L tracking with per-trade attribution and risk metrics
  • Added circuit breaker for maximum daily loss protection

Telegram Notifications

  • Integrated Telegram group notifications for holder report generation and XBot posts
  • Added ASCII bar graph visualizations in Telegram messages for holder distribution data
  • Built a template system for consistent notification formatting with configurable delays to prevent rate limiting

Authentication & Social Login

  • Configured X/Twitter OAuth 2.0 and GitHub OAuth for user authentication
  • Stored credentials securely via Lovable secrets management
  • Added Google OAuth as the primary social login option
Key Decisions
  • Rebuilt the Mesh Network from a display tool into a search-first investigation interface after recognizing a 200-item paginated list was impractical for 97,000+ records
  • Confirmed Reclaim Rent does not create wallet bundling — each wallet independently closes its own token accounts
  • Adopted warning-only approach for blacklist matches — information empowers decisions without blocking execution

Content & Social Media

  • Added DexScreener Top 200 scraper with auto-queueing for new token analysis
Key Decisions

  • Chose to fix all critical security issues before addressing warnings, with regression testing between each batch
