BlackBox Farm — Development Timeline

A 6-Month Build Log · November 2025 – April 2026

November 2025: Foundation & Data Ingestion

Core Platform Setup

  • Established the scraped_tokens table with RLS policies for token data ingestion from DexScreener and HTML scrapes
  • Built the Token Sets admin interface — a combined view of all discovered tokens with thumbnails, ticker symbols, Raydium listing dates, and creator wallet columns
  • Configured Supabase authentication with super admin roles and service-role access patterns
  • Implemented initial token metadata display with compact, data-dense table layouts

Key Decisions

  • Adopted a single scraped_tokens table as the canonical token registry, consolidating data from multiple scraping sources
  • Established a "tight display" design philosophy — minimal padding, maximum data density across all admin interfaces
  • Chose Supabase as the unified backend for auth, database, edge functions, and storage

Architecture

  • React 18 + Vite + Tailwind CSS + TypeScript frontend
  • Supabase backend with PostgreSQL, Edge Functions (Deno), and Row-Level Security
  • Helius API for Solana RPC and token metadata

December 2025: Trading Infrastructure & Advertising Platform

FlipIt Trading Dashboard

  • Built the FlipIt manual trading tool — enter a token address, fetch live price, execute buy/sell via Jupiter and PumpPortal APIs
  • Implemented secure wallet generation with encrypted private key storage
  • Added emergency sell functionality, position tracking with P&L calculations, and withdrawal to external wallets
  • Integrated Helius Parse Transaction API for accurate on-chain quantity tracking per trade

Banner Advertising System

  • Created the self-service advertiser portal (/buy-banner) with tiered pricing (1hr test tier through 30-day packages)
  • Built payment flow with Solana wallet generation per advertiser, payment detection, and automatic banner activation
  • Developed admin Advertiser Management panel for monitoring accounts, orders, wallet balances, and banner images
  • Implemented auth modal integration to preserve form state during sign-up/login flow

Telegram Channel Monitor & Fantasy Portfolio

  • Built real-time Telegram channel monitoring via bot webhook — ingests token calls from monitored alpha groups
  • Created the Fantasy Portfolio Dashboard — automatically opens fantasy positions on first token mention, tracks price performance, and attributes calls to specific channels
  • Implemented deduplication logic: one token = one fantasy position, earliest mention wins across all channels
  • Added channel-specific caller attribution with proper group name display

Developer Intelligence System (Genesis)

  • Extended developer_profiles, developer_wallets, and developer_tokens tables for tracking token creators
  • Implemented wallet genealogy tracing — follows the funding chain from token mint wallet back through intermediary wallets to the KYC root (Binance, Coinbase, etc.)
  • Added developer risk classification with badges: rug history, wallet bundling detection, slow bleed patterns
  • Integrated developer risk scoring into the Fantasy Portfolio's buy/sell decisions

Security Hardening

  • Fixed advertiser wallet secret exposure — restricted RLS so users can only access their own accounts
  • Removed redundant creator wallet columns after identifying data display duplication
  • Implemented proper auth flow to prevent data loss during banner purchase sign-up

Key Decisions

  • Chose Jupiter as the primary swap aggregator with PumpPortal fallback for bonding curve tokens
  • Adopted encrypted private key storage pattern — keys never exposed to the frontend
  • Decided to run developer genealogy traces before buy execution to inform trading decisions
  • Established the "never disable the buy button" principle — warnings are informational, never blocking
